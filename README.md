# Jenson Huang's Great Game

A multiplayer mod for Victoria 2 (3.04, Heart of Darkness). China has westernised and broken into
35 warlord cliques, 20 of them built to be played; the rest of the world is partially westernised,
uncivilized or empty and open to colonisation.

## Install

1. Copy the `Warlord Era` folder and `Warlord Era.mod` into `Victoria 2/mod/`.
2. Start the game, tick **Jenson Huang's Great Game** in the launcher, and play.

Every player in a multiplayer game needs the same copy.

## What is in it

- 35 Chinese cliques on 137 new provinces and 92 new states, each major with its own culture,
  rival, partner, modifiers and decisions.
- The Sikh Empire, Persia and Mongolia as playable uncivilized powers.
- Western and central Europe as one backward Holy Roman Empire.
- Technologies, inventions and units from RobloxDoD 1.8; decisions tied to technologies.
- Regional formables limited to their own cliques, and mutually exclusive national choices.
- State-size war goals in the style of DoD Heartbreaker, national focuses from IGoR,
  a World Bank on the Falklands, and migration to South East Asia in the style of Vae Victis.

## Layout

| Path | What it is |
|---|---|
| `Warlord Era/`, `Warlord Era.mod` | the mod itself |
| `tools/` | the Python scripts that generate the mod from a vanilla install (`tools/build.sh`) |
| `warlord-era-design.md` | design notes |
| `victoria2-modding/` | notes and scripts on Victoria 2 modding pitfalls |
